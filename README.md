# Harmonia / 和弦

Harmonia 是一个自托管的环境变量同步工具：在手机上集中管理环境变量，按设备授权，同步到电脑和运行环境中使用，减少重复配置和手动传递密钥。

## 功能

- **集中管理**：按项目或用途组织环境，修改后同步到所有授权设备。
- **按设备授权**：为每台设备选择可访问的环境，设置只读、读写或管理权限及有效期。
- **多环境组合**：在本机同时启用多个环境，同名变量按优先级合并。
- **本机覆盖**：设置仅在当前设备生效的值，不上传到其它设备。
- **自托管与加密**：服务部署在自己的账号下；变量在客户端加密，服务端仅保存密文。

## 组件

| 组件 | 说明 |
| --- | --- |
| [服务端](https://github.com/harmonia-vault/server) | 账号与加密同步服务，可一键部署到 Cloudflare Workers |
| [手机端](https://github.com/harmonia-vault/mobile) | Android 与 iOS 应用，管理环境、变量和设备授权 |
| [命令行客户端](https://github.com/harmonia-vault/core-go) | 在电脑和服务器上同步并使用变量 |
| [协议](https://github.com/harmonia-vault/protocol) | 客户端与服务端共用的消息格式，供兼容实现参考 |

## 快速开始

1. 按 [服务端说明](https://github.com/harmonia-vault/server) 部署服务，获取 HTTPS 地址。
2. 在手机端填写服务地址，注册账号、保存恢复码，并创建环境和变量。
3. 在电脑上使用命令行客户端连接同一服务并发起配对，在手机上选择授权的环境、权限和有效期。
4. 在电脑上启用环境，通过 `harmonia exec` 启动程序即可使用变量。

## 注意事项

- 已运行的程序不会获得新变量，需重新启动。
- Harmonia 用于分发配置，不限制程序对已获得变量的使用。
- 恢复码遗失后只能重置账号，重置会删除原有数据，请妥善保存。
