# Harmonia / 和弦

Harmonia 用手机管理环境变量，并将它们同步到你授权的电脑或运行环境。把项目所需的配置整理到不同环境中，为每台设备选择权限，就能减少重复配置和手动传递密钥。

## 可以做什么

- **集中管理**：创建环境，添加或修改变量，在授权设备间同步。
- **按设备授权**：选择设备可访问的环境，设置只读、读写或管理权限，以及有效期。
- **按本机需要组合**：启用多个环境并调整优先级；同名变量以高优先级为准。
- **保留本机差异**：设置只在当前设备生效的覆盖值，不上传到其它设备。
- **自行托管**：使用自己的 HTTPS 服务地址；变量在客户端加密，服务端保存密文。

## 开始使用

准备好 Harmonia 手机端、对应系统的命令行客户端，以及一套可连接的服务。

1. 按 [服务端说明](https://github.com/harmonia-vault/server)部署服务，取得 HTTPS 地址。
2. 在手机端填写服务地址，注册账号并按提示完成邮箱验证。
3. 初始化账号，妥善保存恢复码并完成确认，然后创建环境和变量。
4. 在电脑上连接同一服务并发起配对；在手机上核对设备，选择环境、权限和有效期。
5. 在电脑上启用所需环境。后续通过手机或 CLI 修改共享变量，或设置本机覆盖值。

具体操作见 [手机端](https://github.com/harmonia-vault/mobile)和 [CLI](https://github.com/harmonia-vault/core-go)。

## 使用须知

- 已启动的程序不会自动获得新的环境变量；请使用客户端支持的终端接入方式或重新启动程序。
- 程序仍可读取分配给它的环境变量。Harmonia 减少手动配置，不隔离程序与其凭据。
- 恢复码不是数据备份；邮箱重置会删除旧账号数据。请妥善保存恢复码。
- 当前为实验性软件，请先使用非生产数据。

## 项目入口

| 组件 | 用途 |
| --- | --- |
| [手机端](https://github.com/harmonia-vault/mobile) | 管理环境、变量和设备授权 |
| [命令行客户端](https://github.com/harmonia-vault/core-go) | 在电脑和运行环境中使用变量 |
| [服务端](https://github.com/harmonia-vault/server) | 自托管账号与加密同步服务 |
| [协议](https://github.com/harmonia-vault/protocol) | 连接兼容客户端和服务端 |
