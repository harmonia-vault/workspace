# P1 恢复桥与 P3 账号重置客户端接线进度

本次公开必要的 Go 源码、脱敏测试和结果摘要；P1/P3 产品流程尚未完成，能力开关未开放。

P1 增加环境/角色/期限显式登记的 B3a 原生接线及 B3b 正式激活接线。接受登记仍处于受限状态；只有成熟 Boot、完整 Pull、当前授权验证与最终整份状态 CAS 保存成功后才返回可信 binding 和获准变量视图。取消、保存失败或撤销不会返回可信成功；重试绑定同一原 ID 与内容摘要。冷恢复使用已保存的 DAG 来源，不绕到旧流程。

最终 Go 候选的定向 race 5 主测试通过（1.366 秒），真实 HTTPS/Node SQLite/HPKE→Boot/Pull→最终 CAS 主链 1 主测试通过（包 28.820 秒），vet 通过。主链实际覆盖保存失败后原操作重试、冷恢复零网络、fresh Pull、真实 Admin 签撤销后的当前拒绝与冷来源失效。首次未用 import 编译失败与两次 vet 准备路径失败保留；它们没有被计作业务测试通过。此前独立 B3a 的历史结果不与本次最终快照合并计数。

P3 新增独立 accountreset 客户端，使用现有邮件证明协议。密码仅 SHA256 后固定为原请求；结果未知必须先查询，pending 不自动提交，重试不能更换密码或证明。严格校验账号与 generation；取消后拒绝晚到结果。最终纯内存 race 7 主、5 子测试通过（2.450 秒），vet 通过（3.551 秒）。未监听 HTTPS、发邮件或运行手机。

P3 原请求目前仅在 RAM；进程丢失后只能持原邮件证明查询，不能构造替代密码伪称原重试。手机接线仍需实际验证证明、匹配当前账号与本机槽，并完成真实本地清理。重置不恢复旧 vault，不赋予设备信任。

SDK、系统强认证、Flutter 界面、邮件和最终产品验收尚缺；没有最新五仓全套通过的声明。固定剩余范围见 [PRODUCT-ACCEPTANCE.md](PRODUCT-ACCEPTANCE.md)，机器可读摘要见 [结果](evidence/p1-p3-native-source-result.json)。项目仍为实验实现，不可宣传生产可用。

## P2 当前授权提示与 P3 原生清理接线

P2 已公开独立 pending V3/V4 查询：fresh Boot/Pull 后获取有限提示，再检查当前权限。只返回原请求 ID、发起设备 ID、状态和到期时间；它不构成批准依据，也不伪造设备名称、平台或序号。真实 HTTPS 主链验证实际待批请求、失效后的迟到提示拒绝和签名降权后的拒绝。Flutter 已接显式设备/环境角色/期限管理，提交成功仍走原下发流程；结果未知保持原事务，离线恢复不会误报在线。
