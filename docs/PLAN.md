1. **M0 盘点与基线**：相关工作规范和 memory_summary（不读 sessions）、GitHub 身份/组织权限、工具/VM；保存完整设计；秘密/个人数据检查后立即初始化并公开 MIT 五仓库。
2. **M1 首个可测试纵向切片**：确定性协议/向量；成熟 AEAD、签名、HPKE；本机合并、override、逐 key 恢复、到期清理和 CLI；服务端账号持久化、序号、幂等与当前授权；合成端到端测试。生产路径不得提供无证明的设备信任绕过。
3. **M2 配对与账号生命周期**：成熟 SPAKE2、手机审批/管理签授权、HTTPS 登录/Argon2id、独立注册/验证开关、发信验证/重置、多账号隔离和检查点。尚未实现的控制默认拒绝。
4. **M3 恢复与轮换**：种子分用途派生/恢复封套、受限恢复会话、绑定单次挑战、完整重输新码、原子钥匙/封套切换、账号 generation 重置、结果不明查询。
5. **M4 本机系统集成**：按用户开机服务、原子 shell fragment、Windows 用户 registry、显式勾选导入、暂停/撤销/退出、崩溃幂等收敛；隔离 VM 账号验证，不污染宿主。
6. **M5 移动与运行时验收**：验证订阅/真实参数后按实际需要及用量动态使用 Claude Opus 5.5 medium 编写 UI；Flutter+Go、Android 钥匙保护/CRUD/审批/恢复和模拟器；保留 iOS 兼容并如实报告未跑检查。Node SQLite 重启与 Workers D1/DO/Argon2 运行时本地实测，不部署。
7. **审查交付**：刷新 submodule 固定提交、秘密/个人数据复查，推送经过测试的源码和证据，报告路径、链接、通过/失败/未跑以及所有未完成安全门槛。

持续按可测试里程碑推进，不在脚手架结束。目标涉及多轮持续实现；每个已验证结果保存提交，设计目标不能冒充实现结果。所有项目说明文档使用中文。

用户已确认的新要求，不代表以下实现已通过。唯一一次集中 Claude Opus 5.5 medium 调用负责本轮信息架构；新增合同、安全状态和测试由 Codex 实现，不连续消耗订阅。

1. 新安装首屏只填 HTTPS 服务地址。Next 必须实际验证 Harmonia 产品身份、共同协议 major、服务可用并取公开最小 `initialRegistrationAvailable`、`allowRegistration`、`emailVerificationRequired`；普通站点200不是成功。全新未完成首注册的实例默认独立注册页，已完成实例默认登录；allow=true提供注册入口，false只允许尚未完成的实例首号。错误留在当前页，精确区分离线、无效地址、非本产品、协议不兼容；快速点击仅一次在途意图。
2. 首号完成标记持久、原子唯一；不同邮箱待验证申请不占用首号，完成证明后竞选原子首号决定，不因删除或重置账号重新开放。用户明确接受公开实例先到先得风险，部署时提示先注册再公开，不增加令牌、邀请或SMS。邮箱验证只对新注册在申请时冻结要求，不回头锁旧账号；重置仍须新的邮件证明。
3. 账号登录与可信设备分开。未可信者仅授权/受限恢复向导；先受限、完整新码回填和显式环境/角色/期限，不得经返回、深链、重启或fixture进入vault。可信首页为环境列表→环境详情变量→独立添加/编辑；设备一级列表/状态、二级授权详情和角色编辑；设置中的账号安全和恢复码为二级。演示仅显式开发入口。
4. 前台新授权按稳定ID/代际去重，仅一个主动提示，进入详情后最终确认设备、环境、角色和期限并系统认证。取消不反复弹，过期/撤销清理，设备入口显示pending badge；不增加后台推送或权限。没有真实请求能力时不伪造服务事件。
5. 设置可开启进入App身份验证；冷启动和真正后台返回先隐私遮罩再解锁，系统强生物/设备凭据优先，仅确无此能力时App PIN fallback（至少6位、独立随机salt、成熟密码验证、持久失败限流）。App解锁不授予账号登录或设备信任。取消/失败不降级；敏感审批/导出仍逐次系统强认证。短暂系统窗口inactive不能循环锁或销毁恢复进程句柄。无系统认证时如何允许敏感操作尚须明确安全权衡，当前不弱化原生gate、不将短PIN当vault密钥。
6. 已有有效保护状态启动进入系统解锁/主页，退出可保留服务地址回登录；切换服务须清旧session/钥匙/cache并隔离命名空间。忘记App PIN提供安全清本地后重新登录/授权，不绕过E2EE。验证冷启动、后台、系统窗口返回、取消、深链、快速点击、logout/switch和App kill；实际截图须标明合法状态并仅含合成内容。
