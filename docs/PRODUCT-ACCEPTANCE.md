# 固定剩余产品验收清单

更新时间：2026-10-04 UTC。M2 未完成，以下八项仅是 M2 的固定剩余范围，不代表完整项目的全部范围。完成一项才勾选，并填写实际来源、结果和证据；组件测试通过不代替产品流程。历史通过、失败及其限定范围仍见 [STATUS.md](STATUS.md)。

## 执行规则

复用已验证的身份检查、传输、认证窗口和精确清理辅助函数。VM、账号、窗口、端口、产物 SHA 等从已核验的观测记录及构建清单自动传递，不在消息或脚本之间手抄。生成的执行输入必须绑定原记录摘要；发现身份变化仍停止，不能自动接纳新身份。

公开源码数据与执行输入分别检查。源码保留路径、所有者、无符号链接、大小、完整 SHA 及读取前后身份检查；归档的组可写位不能被误当成执行权限缺陷。二进制、控制脚本、SSH 材料和私有目录继续使用严格权限要求。每次真实运行前，在宿主用同一前置代码完成最小干运行，确认记录解析、文件角色、命令生成和清理范围，不连接 VM、不设置凭据。

每行只运行达到完成条件所必需的产品流程。出现具体失败时保留原始结果，定位后只复验受影响范围。新增测试仅用于证明当前行的明确失败或未证边界，不另开无关矩阵。PASS、FAIL、UNRUN 分别记录；执行工具返回成功不等于产品动作成功。只用合成账号、凭据和隔离目录，保留未知资源，精确清理本次对象。

## 剩余八项

- [ ] **P1 Android 恢复向导可用闭环。** 从真实手机界面输入旧恢复码，保持受限状态；显示新码并要求完整重输；完成轮换后显式选择环境、角色和期限登记本机；正式 Boot/Pull 和本机持久保存完成后才能进入管理。原 ID 结果未知须查询原事务，取消和保存失败不得生成新写。重复恢复使用现有 DAG 协议。当前恢复与登记 Go 业务已有实现，原生及 Flutter 接线未闭环；恢复后专用 DAG 高层写入和管理仍须补齐，已有只读 fullView 不能算可管理；非空 B1/B2 和 B3a 桥是此项内部必要接线，不另扩验收范围。

- [ ] **P2 Android 授权管理与前台请求闭环。** 在实际界面处理一个真实 CLI 请求，明确环境、角色、期限；设备列表和授权详情与已验证状态一致，单请求去重，取消、到期及撤销清理提示。完成一次授权变更或撤销并验证 CLI 当前请求被正确限制；不增加后台推送。既有 CLI3 批准主链证据保留，不能代替尚缺的管理界面。

- [ ] **P3 手机账号重置入口闭环。** 实际界面通过合成邮件证明和破坏性确认执行重置；generation 隔离使旧设备和会话失效，旧 vault 不恢复，永久首号策略不重开。使用隔离邮件夹具，不读取用户邮箱或真实 SMTP 凭据。Go 邮件入口、Flutter 协调器及七动作端口已公开；真实 HTTPS/SQLite 的原证明、未知提交后查询和新代际登录验证通过。手机页面路由与 Android 七动作原生通道已接通源码；系统删槽和实际界面产品流程仍未验收。

- [ ] **P4 Android 最终账号与本机生命周期。** 在同一明确固定的产品快照完成已有账号/CRUD 路径及必要的后台取消、原 ID 冷启动续办、切换服务或账号、授权过期/撤销与正常退出。保持同一下发流、原值恢复与无关配置不动。已有独立退出、原 ID 续办和 PIN 最小流程通过分别保留；只补最终接线影响的缺口，不重跑无关组合。未完成流程的能力不得提前开放。

- [ ] **P5 Linux 正式安装器闭环。** 对保留的历史 simple 收据执行正式离线卸载；在同一隔离测试账号新装 exec 服务，真实配对并 Start/Boot/Pull；验证必要的无人登录重启和终端接入；最后正式离线卸载、托管项恢复及精确清理。历史内核纵链通过和本次 5 主/4 子临时文件系统合同通过不是这一项的完成证明。后续真实新装、PAKE、Start/Boot/Pull 和同安装无人登录重启已 PASS；原整轮 FAIL 于正式离线卸载 linux_install_state_invalid。随后同一安装、同一收据的正式卸载续办实际 PASS，安装资源均已移除；原失败原因尚未确认。原 post-reboot shell 已退役，其卸载后的同 shell 恢复断言未执行；已有显式 release 恢复及持久状态清理证据分别保留，随后独立合成真实 shell 自动恢复 PASS，原值恢复、新增项移除且无关项保留；这不追认已退役的原 shell。测试账号与三个 PASS 诊断对象精确清理已 PASS。详见 [本轮续办验证](M2-RESUMED-VALIDATION.md)。

- [ ] **P6 macOS 正式安装器闭环。** 当前专用 stage 的传输与权限已核验；安装前只读检查仍因 print-disabled 条目格式与解析器不符而拒绝；实际只读探针已确认 disabled 字面值；仅修正该解析器的源码已公开于 core-go `b6c8f9d`，263 项受影响 race 测试通过，尚未重跑正式安装。解决该检查后，完成正式安装、配对、LaunchDaemon 启动与下发、必要的无人登录重启及终端接入，再正式离线卸载并恢复托管配置。复用已有正常登录与公包传输工具，不改旧未知目录、不反复重做身份工具。原固定版本内核纵链通过不能代替新版安装器验收。

- [ ] **P7 Windows 普通用户与服务闭环。** 用户已明确同意当前首次数据跨境传输条款；恢复观察时已在合成用户桌面，主任务未另行点击条款。普通用户身份已实际核验；存储首轮两个主测试通过，一个夹具断言失败。仅修正夹具后，受影响的一主九子原生复验全部通过，且本轮残留精确清理完成；原失败确认为新文件权限检查先拒绝、明文长度为零，原记录保留。标准 SCM 普通账号服务、CLI 认证 IPC 与卸载恢复已有私有源码候选和宿主测试；共享账号权限回收已补齐完整枚举和前后快照检查，无法完整判定时保留权利与未完成收据；私有候选通过宿主定向测试，尚不能当作真实服务结果。正式 provider/CLI/SCM 启动、无人登录 Boot/Pull 与卸载恢复仍未完成。既有 SYSTEM 测试和 AccessCheck 不代替普通用户或真实服务结果；已被中止的专项实验保持原阻塞记录。

- [ ] **P8 固定最终快照验收与交付。** P1–P7 逐项记录完成或精确外部阻塞后，冻结五仓提交，在同一清单上做有界集成验证、公开前秘密及个人数据检查，更新 submodule、状态与操作文档。不得把不同源码的局部通过拼为最新五仓全部通过。CI/CD 和自动更新按已授权计划在 M2 后继续；本轮不创建 Tag、不发布 Release 或安装包、不部署真实线上服务。

## 本轮边界

iOS 按用户要求现在并行实施，完整产品验收另列，不替代 Android 首版。已有 iOS 初始化、CRUD 和退出基础流程证据保留；当前继续原生持久化与 Flutter 生命周期接线。CI/CD 和自动更新已获授权，在 M2 后继续，不因本清单未列出而取消。真实外部邮件投递、Workers 线上资源配额和独立安全审计仍明确未验；不为额度降低参数，不为测试使用用户真实凭据。Windows 当前条款等待已解除；普通用户存储已有上述限定通过证据，真实服务仍须独立验收。

完成记录统一写为：`P编号 / 固定源码或产物摘要 / 产品动作 / PASS或FAIL / 清理结果 / 证据链接`。只在对应产品条件实际满足后将 `[ ]` 改为 `[x]`；测试脚本前置通过、编译或诊断结果不勾选产品项。
