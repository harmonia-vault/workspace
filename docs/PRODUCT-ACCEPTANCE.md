# 固定剩余产品验收清单

更新时间：2026-10-04 UTC。M2 未完成，以下八项仅是 M2 的固定剩余范围，不代表完整项目的全部范围。完成一项才勾选，并填写实际来源、结果和证据；组件测试通过不代替产品流程。历史通过、失败及其限定范围仍见 [STATUS.md](STATUS.md)。

## 执行规则

按用户最新确认的[分层测试预算](TESTING.md)验收：共享业务单测一次，服务端往来用真实接口集成；Android/iOS 仅保留原生差异及各一条最短主流程。下方用户行为条件不等于两端逐组合 UI 测试要求；已发现的实际原生问题仍定向复验，未变通过结果复用。

复用已验证的身份检查、传输、认证窗口和精确清理辅助函数。VM、账号、窗口、端口、产物 SHA 等从已核验的观测记录及构建清单自动传递，不在消息或脚本之间手抄。生成的执行输入必须绑定原记录摘要；发现身份变化仍停止，不能自动接纳新身份。

公开源码数据与执行输入分别检查。源码保留路径、所有者、无符号链接、大小、完整 SHA 及读取前后身份检查；归档的组可写位不能被误当成执行权限缺陷。二进制、控制脚本、SSH 材料和私有目录继续使用严格权限要求。每次真实运行前，在宿主用同一前置代码完成最小干运行，确认记录解析、文件角色、命令生成和清理范围，不连接 VM、不设置凭据。

每行只运行达到完成条件所必需的产品流程。出现具体失败时保留原始结果，定位后只复验受影响范围。新增测试仅用于证明当前行的明确失败或未证边界，不另开无关矩阵。PASS、FAIL、UNRUN 分别记录；执行工具返回成功不等于产品动作成功。只用合成账号、凭据和隔离目录，保留未知资源，精确清理本次对象。
